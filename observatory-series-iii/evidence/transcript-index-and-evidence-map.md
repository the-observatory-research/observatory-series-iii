## 1. Record Purpose and Preservation Conditions

This document provides a chronological navigation index for the complete Series III conversational transcript.

Unlike Series II, which followed a fixed transformation pipeline, Series III developed through changing participant configurations, conversational conditions, and reasoning procedures.

The source archive therefore remains preserved as a continuous transcript rather than being reconstructed into separately formatted model-response records.

This index identifies significant experimental transitions, recorded interventions, behavioral observations, and corresponding source locations.

All source material remains in the complete transcript.

### Source Integrity

The original compiled transcript is preserved separately from this navigation index.

No conversational output is replaced by its subsequent interpretation.

Errors, repeated messages, source-attribution inconsistencies, researcher instructions, model contributions, formal departures, and post-formal exchanges are retained as recorded.

**Archival Principle:** The evidence map provides access to the original sequence. It does not substitute for the sequence.

### Source Pagination and Reference Integrity

All page references in this index correspond to the original 309-page Series III transcript compiled in Google Docs.

The Obsidian edition may differ in pagination, spacing, heading placement, and document layout. These presentation differences do not alter the source locations identified in the original reference document.

For archival consistency, the original Google Docs compilation serves as the pagination authority. A fixed-layout PDF export should be retained alongside the source document to preserve these references.

Event identifiers (`SIII-E001` through `SIII-E020`) remain stable across document formats and may also be used as internal navigation anchors within Obsidian.

**Reference Convention:** `SIII-E012 — Original Transcript, p. 278`

Page references identify locations in the original compilation; event identifiers provide format-independent navigation.
