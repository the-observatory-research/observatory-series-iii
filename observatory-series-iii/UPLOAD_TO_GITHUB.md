1. Create a repository named **`observatory-series-iii`** on GitHub. Begin with **Private** visibility for review and **No license** until redistribution has been assessed.
2. Download and extract `observatory-series-iii-github-ready.zip` on your Mac.
3. Open the repository's **Code** tab and choose **Add file → Upload files**.
4. Upload the **contents** of the extracted `observatory-series-iii` directory, **not the ZIP** itself.
5. Preview the README and open `evidence/events.csv` to ensure all 20 events display correctly. Run the repository validation utility on your Mac, if convenient.
6. Inspect `transcripts/SERIES III - TRANSCRIPT.docx` for personal/private material and third-party model-output permissions before changing visibility to Public.
7. When ready, edit the repository **About** description and link a verified Series III permalink from The Observatory research archive.
